Using the catalogue

The filter box accepts an expression over the column names, for example Omega_m > 0.3 and status == "galaxies" or seds_layers == n_layers. Comparison and arithmetic operators, and, or, not and the functions abs, log10, sqrt, min and max are available. Column names are shown in the Columns panel; hover a column heading for its description.

The status of a run is inferred from the files present on disk, in order: selected (region chosen, nothing run), ics, started, completed (SWIFT finished), structure (HBT-HERONS), trees, masks and galaxies (at least one SHARK layer; the SHARK and SED layer columns record how many are complete). Design points beyond the catalogued regions are not selected.

The pivot view cross-tabulates any two columns, so for example rows by status and columns by the number of completed SED layers show what has been run on top of each region. Open a row to see its full record and the parameters and completion state of every galaxy layer.
